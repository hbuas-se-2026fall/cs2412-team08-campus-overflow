四、我在团队中的定位



\- 可以带别人的：站会主持与流程把控、看板维护、需求梳理与用户故事拆分、会议记录与文档整理。

\- 需要别人带的：Spring Boot 后端实现、JUnit 5 与测试工程化、Docker 与 CI 配置、前端页面。

\- 希望在本学期补齐的短板：看懂并参与代码评审、把 CI 门禁从"理解"变成"能配置维护"、把需求讲成开发可直接开工的条目。



五、组队互补建议



我偏向"流程 + 文档 + 协调"这一侧，理想的队友组合是：一位能定义价值与验收标准的 PO，以及三位能覆盖后端、测试、前端的 Developer。本届 5 人组合（PO 1 + SM 1 + Developer 3）与该结构吻合。
