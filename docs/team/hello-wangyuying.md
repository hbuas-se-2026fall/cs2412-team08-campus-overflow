## 我希望在这个项目中学到什么

1. 把 **分支 → PR → 评审 → 合并 → CI** 这条链路走完整、走规范，而不是一个人闷头写完再一次性上传
2. 养成先读测试、再写实现的习惯，让领域层的不变式由测试守住，而不是靠"我觉得应该对"
3. 弄懂 DDD 的聚合与上下文边界到底怎么落到**目录结构和模块依赖**上，而不只是背概念
4. 学会在团队里做技术决策并写清理由（ADR），让后来的人看得懂为什么这么定
