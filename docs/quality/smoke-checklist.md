# 冒烟检查清单（Lab8 上线后执行）

执行前提：`docker compose up -d` 已完成，健康检查通过，域名可访问。
执行方式：逐项执行并记录结果；任何一项失败按 `defect-list.md` 登记并定级。
记录格式：通过 / 失败（附请求 id 或截图） / 阻塞（无法执行的原因）。
