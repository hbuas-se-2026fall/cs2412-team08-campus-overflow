# Lab8 回归测试与缺陷登记方案

本人在 Lab8 承担「回归与缺陷登记」，属于上线后的验证环节。本方案说明回归的分层、准入准出、时间盒，以及缺陷从发现到关闭的流转规则。执行用的逐条用例见 `regression-checklist.md`，缺陷登记见 `lab8-defect-log.md`。

## 一、职责边界

回归与缺陷登记由本人负责，前置资源由分工内其他人提供，缺一即视为环境未就绪：

| 依赖项 | 提供方 | 用途 |
| --- | --- | --- |
| 测试服务器子域名、SSH 账号与密钥 | 王钰滢、张嘉雨对接课程方 | 部署 Job 与线上 URL 提交物 |
| 镜像构建与推送、部署 Job | 王钰滢（容器化）、张嘉雨（CI/CD） | 回归对象的来源 |
| Prometheus / Grafana 面板 | 李增艳 | P3 观察项取数 |
| 上线通告与友测邀请 | 邹园园 | 真实流量与外部反馈 |

## 二、环境阻塞判定

环境不满足时不启动回归，标记为「阻塞」而不是「失败」，避免缺陷表被环境问题污染。

| 编号 | 检查 | 判定 | 不满足时 |
| --- | --- | --- | --- |
| E-01 | 子域名解析 | `nslookup <域名>` 返回课程分配记录 | 全量阻塞 |
| E-02 | 首页可达 | `curl -I https://<域名>/` 返回 200 | 全量阻塞 |
| E-03 | 健康检查 | `/actuator/health` 为 `UP`，`/health/readiness` 为 `UP` | 全量阻塞 |
| E-04 | 部署记录 | Actions 最近一次 deploy 成功，镜像 tag 与 commit 对应 | 全量阻塞 |
| E-05 | 监控可达 | 能登录 Grafana 并看到曲线 | 仅 P3 阻塞 |

## 三、准入与准出

准入条件全部满足才开始计时：

1. 部署 Job 成功，运行中的镜像 tag 与目标 commit 一致
2. 健康检查双 UP，容器无 unhealthy
3. Flyway 迁移完成，`flyway_schema_history` 最新版本与 main 一致
4. 数据库字符集为 utf8mb4，ngram 分词参数已生效

准出条件全部满足才认为回归结束：

- P0 用例 100% 通过
- P1 用例通过率不低于 95%，且无未关闭的 P0、P1 缺陷
- P2 缺陷全部登记（允许开放，但必须定级与分派）
- 冒烟与回归期间 5xx 为 0，接口 p95 不超过 500 毫秒
- 缺陷表中 P0、P1 的状态为「已关闭」或「已确认且已排期」

## 四、分层与时间盒

| 层 | 覆盖范围 | 时间盒 | 说明 |
| --- | --- | --- | --- |
| P0 | 环境可达 + 主链路（注册、登录、提问、回答、投票、评论、采纳） | 部署完成后 30 分钟内 | 挂了就不用继续往下跑 |
| P1 | 核心业务全量：问答、评论投票、声誉悬赏、搜索通知、课程与管理 | 当日 | 决定能否交线上 URL |
| P2 | 边界值、权限矩阵、错误码映射、并发与重复提交 | 次日 | 覆盖面最广，可分批 |
| P3 | 延迟、错误率、日志、重启恢复、回滚 | 上线通告后 24 小时内 | 依赖监控与真实流量 |

## 五、执行与记录

- 接口级执行用 `curl` 或 `Invoke-RestMethod`，保留请求与响应原文，个人信息按 `Masking` 规则脱敏
- 每条结果记三态：通过、失败（附错误码与请求 id）、阻塞（附原因）
- 成功项统一记「2xx + 可观察结果」，不硬编码具体状态码；失败项记具体错误码，错误码到状态码的映射以 `docs/错误码.md` 为准
- 用例失败 24 小时内登记到缺陷表，定级后分派；修复后用对应用例复跑，通过才关闭
- CI 的 smoke test 只验健康端点，不覆盖业务，仅作准入依据，不能替代本清单

## 六、缺陷流转规则

| 等级 | 判定标准 | 响应时限 | 关闭条件 |
| --- | --- | --- | --- |
| P0 | 阻断上线、数据错乱、安全漏洞 | 立即，当日修复 | 修复提交 + 复跑通过 + 证据留存 |
| P1 | 主流程不可用、有绕过路径、错误码与文档不符且影响判定 | 当日 | 同上 |
| P2 | 边界与体验缺陷、文档缺漏、日志缺失 | 3 个工作日内 | 修复或明确降级为不修并写明理由 |
| P3 | 性能优化、可读性、非阻塞项 | 下个迭代 | 记录在案即可 |

初判与分派由本人完成，修复由模块归属人负责，复验与关闭由本人执行。跨模块缺陷由分工负责人裁定归属。

## 七、降级与风险

- 环境未就绪：全量标阻塞，输出「环境未就绪」报告，缺口在群里点明，不写入缺陷表
- 服务器只开 80 端口：HTTPS 与会话安全相关项降级为「不适用」并记录，不判失败
- Grafana 未接入：P3 观察项改用 `/actuator/metrics` 与后端日志取数
- 回归时间不足：优先保 P0 与 P1，P2 按模块抽样并注明未覆盖范围，不得默认通过
