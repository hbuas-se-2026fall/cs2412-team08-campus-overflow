## 二、功能与监控验收

- [ ] 后端多阶段构建：builder（JDK + Maven）→ runtime（JRE only）；非 root 用户运行；镜像体积有优化；
- [ ] 前端镜像：node 构建 → nginx:alpine；`/api` 反向代理；SPA 路由 fallback 本地验证过；
- [ ] compose 编排：MySQL + Redis + backend + web + Prometheus + Grafana；健康检查与 `depends_on: service_healthy`；环境变量走 `.env` / Secrets；
- [ ] 监控面板：`co_outbox_backlog`、`co_outbox_dead_letters`、`co_reputation_mismatches`、接口 p95、5xx 错误率至少 5 项可观测；
- [ ] 告警规则：至少 1 条（p95 > 500ms 或 5xx > 1%），规则已加载并可触发；
- [ ] 部署后 smoke test 自动调用 `/actuator/health/readiness` 通过；
- [ ] 团队 IM 群已通告上线 URL，邀请其他团队友测（邹园园）。
